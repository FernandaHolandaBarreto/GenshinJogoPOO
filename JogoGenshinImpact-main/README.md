# Aventura da Viajante

Jogo de aventura em Java executado pelo console, inspirado no universo de Genshin Impact. O jogador escolhe Lumine ou Aether, explora regiões, participa de eventos, enfrenta monstros, gerencia personagens e utiliza o sistema de desejos.

## Objetivo
Explore todas as 13 regiões do mapa para concluir a jornada. Se a vida chegar a zero, ocorre derrota. Também é possível encerrar voluntariamente pelo menu.
